# Neraca

Author: demtcsre

## Description

Neraca tua di gudang arsip, kuningannya sudah menghitam. Cuma ada satu posisi
di mana semua lengannya mau diam. Katanya dulu pernah ada yang sempat
menemukannya, tapi catatannya ikut hilang waktu gudangnya pindah.

## Hint

16 huruf, 6 persamaan. Gak ada yang bisa dipecahin sendirian.
