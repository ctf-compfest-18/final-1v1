# Layer Cake

- **Category:** Cryptography
- **Difficulty:** Easy-Medium
- **Time Limit:** 5 minutes

---

### Description

Our pastry chef was preparing an exclusive recipe for the grand finale banquet. To protect their culinary masterpiece from corporate espionage, they baked the secret message deep beneath multiple elaborate wrappings and crusts.

Before vanishing, the chef left behind an encrypted parchment and a cryptic note:

> *"The sweetest reward isn't found on the surface. Like an onion, peel each layer to find the truth inside."*

Can you unravel the pastry chef's multi-layered concoction before time runs out?
